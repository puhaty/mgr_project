# MEMORY

- [Użytkownik sam kompiluje LaTeX](user-compiles-latex-himself.md) — nie uruchamiać scons/pdflatex, czekać na jego wynik kompilacji
- [Schematy robię sam w TikZ](diagrams-tikz-self-made.md) — źródła w tex/fig/*.tikz; użytkownik dostarcza tylko zdjęcia i zrzuty ekranu (tex/img/)
- [Nie zmyślam uzasadnień](no-invented-rationale.md) — decyzje widoczne tylko w kodzie opisuję jako fakt, bez wymyślonego "dlaczego"; pytam, jeśli uzasadnienie jest potrzebne
- [Nie nadmuchuję procesu w "cykl"](no-inflated-process-framing.md) — liniowy przebieg prac to nie automatyczny cykl; oddzielam historię budowy od stanu pracy urządzenia docelowego
- [Nie nazywam notebooków w tekście](no-notebook-filenames-in-text.md) — opisuję modele/proces merytorycznie, bez nazw plików .ipynb
- [Bez gołych zmiennych z kodu w prozie](no-raw-code-identifiers-in-prose.md) — liczby/nazwy narzędzi OK, identyfikatory tylko z odnośnikiem do tabeli lub w tabeli
- [Kod to nie założenie projektowe](code-is-not-design-rationale.md) — przy konflikcie z filozofią pracy (nudging) opisuję idealny zamysł, nie cytuję komentarzy z kodu jako uzasadnienia; pytam zamiast decydować
- [Zakres = Cel Pracy + Wymagania Projektowe](scope-limited-to-cel-i-wymagania.md) — cała praca ma je potwierdzać/odzwierciedlać; nie wychodzę poza nie bez pytania
- [Opisuję efekt widoczny, nie reprezentację wewnętrzną](describe-visible-effect-not-internal-representation.md) — np. rosnące drzewo, nie wskaźnik 0-1000 z kodu
